    What's under the hood

    Hybrid Search

    Combines keyword matching with meaning-based search so acronyms and exact terms are never missed.

    Reranked Results

    A second pass re-orders the best-matching passages before they're used to answer, improving accuracy.

    Streaming Answers

    Answers appear word by word as they're generated, instead of a long wait for a full response.

    Page-Level Citations

    Every answer is followed by the document and page number it was actually drawn from.

    Hallucination Guardrails

    If the document doesn't contain an answer, it says so — instead of making one up.

    Multi-Document Support

    Upload more than one PDF and ask questions that span across all of them.
